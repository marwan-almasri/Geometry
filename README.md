# Geometry

A standalone Swift package providing cross-platform 3D geometric math types — vectors, coordinate systems, rotations, and numerical integration methods — with optional CoreMotion and CoreLocation convenience extensions.

## Modules

| Module | Types |
|--------|-------|
| **Math** | `Angle`, `Accuracy`, `Direction`, `NumericalIntegration`, math utilities, physical constants |
| **Vector** | `Vector3D`, `CartesianVector`, `SphericalVector`, `CylindricalVector` |
| **Rotation** | `EulerAngles`, `Quaternion`, `RotationMatrix`, `Rotation3D` |
| **Motion** | `Heading`, `MagneticField`, `Motion`, `MotionActivity`, `MotionActivityStatus` |

### Platform extensions (conditional)

- **CoreMotion** (iOS, macOS 12+, watchOS, tvOS) — convenience initialisers from `CMAttitude`, `CMQuaternion`, `CMRotationMatrix`, `CMAcceleration`, `CMMagneticField`, `CMMotionActivity`
- **CoreLocation** (iOS, macOS) — convenience initialisers from `CLHeading`

## Installation

Add Geometry to your `Package.swift` dependencies:

```swift
// Package.swift
dependencies: [
    .package(url: "https://github.com/marwan-almasri/Geometry", from: "1.0.0"),
],
targets: [
    .target(
        name: "YourTarget",
        dependencies: ["Geometry"]
    ),
]
```

## Usage

### Angle

```swift
import Geometry

let angle = Angle(degrees: 45)
print(angle.radians)                  // 0.7854 (π/4)
print(sin(angle))                     // 0.7071
print(cos(angle))                     // 0.7071

let sum = angle + Angle(degrees: 45)  // Angle(degrees: 90)
let half: Double = angle * 0.5        // 0.3927 rad
```

### Vector3D

```swift
let v = Vector3D(x: 3, y: 4, z: 0)
print(~v)                              // norm = 5.0

let sph  = v.sphericalVector           // SphericalVector(r:5, θ:90°, ϕ:53.13°)
let cyl  = v.cylindricalVector         // CylindricalVector(ρ:5, ϕ:53.13°, z:0)
let back = sph.cartesianVector         // CartesianVector(3, 4, 0)

let a = Vector3D(x: 1, y: 0, z: 0)
let b = Vector3D(x: 4, y: 3, z: 0)
print(a ~ b)                           // distance = 5.0
```

### Rotations

```swift
// Euler → Matrix → Euler round-trip
let euler  = EulerAngles(roll:  Angle(degrees: 10),
                         pitch: Angle(degrees: 20),
                         yaw:   Angle(degrees: 30))
let matrix = euler.rotationMatrix
let back   = matrix.eulerAngles        // recovers original angles

// Euler → Quaternion → Euler round-trip
let q          = euler.quaternion
let fromQ      = q.eulerAngles

// Quaternion → RotationMatrix
let rm = q.rotationMatrix
```

### Numerical Integration

```swift
// ∫₀^π sin(x) dx ≈ 2.0
let dx     = 0.001
let values = stride(from: 0.0, through: .pi, by: dx).map { sin($0) }

let trap   = NumericalIntegration.trapezoidal(set: values, dx: dx)
let simp   = NumericalIntegration.simpsons(set: values, dx: dx)   // higher accuracy
```

### Math Utilities

```swift
let clamped   = clamp(value: 1.5, min: 0.0, max: 1.0)   // 1.0
let wrapped   = wrap(370, min: 0, max: 360)               // 10.0
let t         = inverseLerp(from: 0, to: 100, value: 25) // 0.25
let mapped    = map(value: 0.5, from: 0...1, to: 0...360) // 180.0
```

### CoreMotion integration

```swift
#if canImport(CoreMotion)
import CoreMotion

let motionManager = CMMotionManager()
motionManager.startDeviceMotionUpdates(to: .main) { data, _ in
    guard let data else { return }

    let euler  = EulerAngles(attitude: data.attitude)
    let q      = Quaternion(quaternion: data.attitude.quaternion)
    let matrix = RotationMatrix(matrix: data.attitude.rotationMatrix)
    let accel  = Vector3D(acceleration: data.userAcceleration)
}
#endif
```
